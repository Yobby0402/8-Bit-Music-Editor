# 设备脚本说明

`device/` 目录目前只保留设备端参考脚本，不再包含桌面应用内置的 WiFi 播放链路。

## 当前状态

- `buzzer_player.py`
  通过串口接收 `频率,占空比,持续时间` 格式的数据并播放。
- `buzzer_player_standalone.py`
  从设备本地读取 `.daf` 文件并独立播放，适合作为实验或离线参考。

## 说明

- 桌面应用内置的 WiFi/Socket 设备连接功能已经移除。
- 如果后续重新引入设备支持，建议以独立模块重新设计，而不是继续复用旧链路。

## 硬件建议

- ESP32 / ESP32-S3
- 有源或无源蜂鸣器
- 合适的供电与驱动电路

## 提醒

这些脚本当前按“参考实现”保留，未纳入桌面应用主流程，也不作为当前版本的正式支持能力。
