# 使用说明

## 启动桌面应用

```bash
python main.py
```

## 常用工作流

1. 新建或打开一个项目。
2. 在统一编辑器和序列编辑器中编辑音符、鼓点和属性。
3. 需要外部素材时导入 MIDI。
4. 需要快速起稿时使用 Seed 生成功能。
5. 完成后保存为项目 JSON，或导出为 WAV / MP3 / OGG / MIDI。

## 常用功能入口

- `文件` 菜单：新建、打开、保存、导入导出
- `播放` 菜单：播放、暂停、停止
- `生成` 菜单：从 Seed 生成音乐
- 右侧 Dock：属性、乐谱片段、播放设置、BPM 编辑

## 辅助脚本

以下脚本仍可作为独立示例使用：

- `quick_demo.py`：快速试听几个基础 8bit 音效
- `demo_sound_effects.py`：交互式音效演示与导出

已废弃的旧测试脚本已从仓库中移除，不再作为当前工程的验证入口。

## 常见问题

### 启动后没有声音

- 检查系统音量和默认音频输出设备
- 确认依赖已经正确安装
- 如果是远程桌面环境，确认音频重定向可用

### MIDI 导入后节奏不对

- 先查看 [BPM 处理流程说明](BPM_处理流程说明.md)
- 再查看 [为什么使用秒而不是 ticks](为什么使用秒而不是ticks.md)
